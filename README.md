# Site-fictício — Escritório de Contabilidade

Resumo
- Projeto final do módulo de HTML da OneBitCode.
- Objetivo: criar um site fictício para um escritório de contabilidade, aplicando conceitos de HTML semântico, estrutura de páginas e boas práticas básicas.

Destaques
- Páginas: index.html (home), serviços.html, sobre.html, contato.html.
- Conteúdo fictício: descrição de serviços contábeis, equipe, formulário de contato (estático).
- Responsivo básico, estrutura semântica (header, nav, main, footer).
- Recursos: HTML5 e CSS simples (pasta css/), imagens em assets/images/.

Como abrir
- Método rápido: abrir o arquivo `index.html` no navegador.
- Servidor local (recomendado para relative paths):
    - Python 3: `python -m http.server` e abrir `http://localhost:8000`
    - Ou usar extensão Live Server no VS Code.

Estrutura do projeto
- /index.html
- /servicos.html
- /sobre.html
- /contato.html
- /css/style.css
- /assets/images/ (logotipo e imagens ilustrativas)
- /README.md

Customização
- Substituir textos e imagens por conteúdo real.
- Ajustar cores e tipografia em `css/style.css`.
- Converter o formulário em funcional conectando com backend ou serviços de formulário.

Boas práticas e observações
- Usar tags semânticas para melhor acessibilidade e SEO.
- Testar em diferentes tamanhos de tela.
- Validar HTML e CSS periodicamente.
